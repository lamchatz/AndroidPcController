# AndroidPcController

Android app to manage your pc. 
Opens Spotify, Age of Mythology and Discord, Disney+, Youtube (Home and selected video)

Copy button functionality: 
    Click -> Copy phone's last clipboard entry to pc clipboard
    DoubleClick -> Opens window and copies that text to pc clipboard
    LongClick -> Copy Pc's clipboard to phone

Decrease, Mute/Unmute, Increase sound


Also need https://github.com/lamchatz/PcController.git
